# Challenge: Classes

## Problem

Implement a Thermostat Class

Members:

- `temperature` of type `float` (C or F)
- `mode` (OFF, COOLING, HEATING)
- `location` ("Living Room", "Bedroom", etc.)
- Should be able to display status of thermostat settings (temperature, mode, and location)
- initialization should be done in constructor
- Destructor should contain message that the object is being destroyed
