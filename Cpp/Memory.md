
**Short version:**

- **Stack**
    
    - Stores: local variables, function calls
        
    - Size: small, fixed
        
    - Speed: very fast
        
    - Lifetime: automatic (allocated & freed when functions enter/exit)
        
- **Heap**
    
    - Stores: dynamically allocated data (`new`, `malloc`, etc.)
        
    - Size: large, flexible
        
    - Speed: slower (needs manual or garbage-collected management)
        
    - Lifetime: you control it (or GC does)
        

**In one line:**  
**Stack = automatic + fast. Heap = manual/GC + flexible.**
