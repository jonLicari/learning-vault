
### Const vs Constexpr

Both keywords are used to define a constant variable or function but where they differ is whether they evaluate at compile time or runtime.

Use **const** when a constant variable or function will need to be **determined at compile or run time.**

Use **constexpr** when evaluating a variable or function **only at compile time**.

```cpp
int temp = rand(); // temp is generated by the random generator at runtime 

  

const int x1 = 10; // OK - known at compile time 

const int x2 = temp; // OK - known only at runtime.

constexpr int x3 = 10; // OK - known at compile time. 

constexpr int x4 = temp; // ERROR. Value of 'temp' is not known at compile time so `constexpr` can't be applied here.
```
